# Android app screenshots

`app-{home,career,mastery,loadout,party,rewards}.webp` were captured directly
from the `valsync_api36` Android emulator on 2026-10-11 using the local 1.8.28
debug APK. They show the current Android UI with the emulator account's data.

A temporary screenshot build hid ad surfaces and the floating bug-report
button before capture. The original Android source files were restored
byte-for-byte after building; this did not change the production app.

Original 1080 × 2400 screenshots were resized to 540 × 1200 and encoded as
WebP at quality 88. No app content was generated or painted into the images.
Keep the gallery disclosure when refreshing these assets.
